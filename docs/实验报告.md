## 二、s768-v2 训练结果

100 epochs / 2.853 小时。最佳出现在 **第 85 个 epoch**：mAP50 0.6239 / mAP50-95 0.38864。

**关 mosaic 没有带来收益**：第 86 epoch 起关闭 mosaic（close_mosaic=15），分数从 0.3886 掉到 0.381~0.383 并一直平到第 100 epoch。

> 与经验预期相反。可能原因：验证集只有 604 张且为分组切分，样本分布有限；关掉 mosaic 后模型面对的"干净构图"与它训练了 85 个 epoch 的拼图分布不一致，短时间内无法适配，而 cos_lr 尾部退火的时间又不够。
> **下一轮可试**：close_mosaic=0（全程开）、或 close_mosaic=30、或把 mosaic 概率从 1.0 降到 0.5。

## 三、推理端多尺度融合（有效，+0.008）

在 604 张验证集上保存 768/896/1024 三档原始预测框，离线扫「尺度组合 × 类内 NMS 阈值」共 25 组。

| 配置 | mAP50-95（本地评测器） |
|---|---|
| 单 768 | 0.3719 |
| 单 896 | 0.3811 |
| 单 1024 | 0.3826 |
| 768+896+1024 | 0.3910 |
| **896+1024, IoU 0.65** | **0.3921** |

- 融合相对最佳单尺度 **+0.008**，相对 768 单尺度 +0.020

> 口径说明：本地 `eval_map.py`（COCO 101 点插值、每图截断 100 框）比 ultralytics 自带 val **系统性低约 0.017**。绝对值以 ultralytics 为准，横向比较用本表。

### 8.2 推理尺度扫描（这是 v3 自己的曲线，不能套用 v2 的结论）

| imgsz | mAP50 | mAP50-95 |
|---|---|---|
| 896 | 0.6503 | 0.3953 |
| **1024** | **0.6638** | **0.4102** |
| 1152 | 0.6598 | 0.4050 |

结论修正：**峰值正好落在训练分辨率 1024 上**，不是"训练分辨率之上再加一档"。v2 是 768 训练、峰值 1024，那是因为它本身训练不足；v3 训满后，尺度错配的代价立刻显现。这条规则可以沉淀下来：**推理尺度的峰值 ≈ 训练尺度，除非模型训练不足。**

### 8.3 融合实验：跨模型有效，纯多尺度无效

在 604 张验证集上扫了 4 个预测源的 15 种组合 × 4 个 IoU 阈值（源：v3 的 896 / 1024 / 1152，加 s768-v2 在 1024 尺度上的预测）：

| 组合 | 最佳 IoU | mAP50-95 |
|---|---|---|
| v3 单 1024 | — | 0.4102 |
| v3 896+1024+1152（纯多尺度） | 0.65 | 0.4022 |
| v3 896+1024 | 0.65 | 0.3985 |
| **v3 896+1152 + v2** | **0.70** | **0.4138** |
| v3 896+1024+1152 + v2 | 0.65 | 0.4129 |

两个反直觉的结论：

1. **同一个模型的多个尺度融合是负收益**（0.4102 → 0.4022）。因为不同尺度的误差高度相关，NMS 把同一个错框在不同尺度下的多个副本保留下来，只增加了假阳性。之前 v2 时代"896+1024 融合涨 0.004"能成立，是因为那时 v2 只有一个模型、且 896 与 1024 差距大；现在 v3 本身就在 1024 拍摄，尺度多样性被吃掉了。
2. **跨模型融合（不同训练尺度）是正收益**（0.4102 → 0.4138）。768 训练的 v2 和 1024 训练的 v3，对同一个目标的定位偏差模式不同，NMS 能在两者之间挑到更准的那个。
